# Antivirus & Malware

I denna övning ska vi testa antivirusfunktioner genom att läsa en malware fil med ett python script.

## Systemkrav

Windows operativsystem

## funktion

Läser av dator efter ECIAR signaturer, bekräftar om signatur har hittats

## Användning

tillåt scriptet att köras:

```bash
chmod +x av-test.py
```
kör scriptet:

```bash
./av-test.py
```
