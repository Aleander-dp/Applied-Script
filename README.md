# Applied Script
Här finns några övningar + ett projekt som jag skapade under kursen Applied Script.

## filer
Detta Repository innehåller övningar 1 -3 + ett projekt.

## Syfte
Syftet med denna kurs var att skapa script med enklare funktioner som underlättar ens dagliga arbete genom att automatisera mindre repetitiva uppgifter. Jag valde att skapa ett script som genomför grundläggande kontroller på SUID, Kernel och uid0 användare, som sedan loggas för att kunna se skillnader med tiden.
