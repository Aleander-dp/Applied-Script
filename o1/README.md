# Systeminformations insamling

Detta Script ger gruundläggande information om användaren och enheten den användes på.

Detta inkluderar operativsystem, användare, nätverksinformation, datum & hur länge enheten har varit påslagen.

# Användning

Detta script används genom att skriva in följande i terminalen:

chmod +x ovning1_script.py

./ovning1_script.sh
